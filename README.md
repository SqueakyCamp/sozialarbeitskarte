# Sozialarbeitskarte Wien

Interaktive Karte der Einrichtungen der Sozialen Arbeit in Wien: filterbar nach Arbeitsfeld (Wohnungslosenhilfe, Notquartiere, Jugendarbeit, Suchthilfe, Gewaltschutz …), mit Beschreibung, Träger, Förderung, Videos und Artikeln. Kartenlayer: basemap.at, Orthofoto, Luftbild Stadt Wien, U-Bahn, S-Bahn, Straßenbahn, Bezirksgrenzen.

**→ https://squeakycamp.github.io/sozialarbeitskarte/**

Quellen: [Sozialinfo Wien](https://www.wien.gv.at/sozialinfo/) (Fonds Soziales Wien), [Offene Daten Wien](https://data.wien.gv.at) (CC BY 4.0), Websites der Einrichtungen (kurze Auszüge mit Quellenlink), basemap.at, OpenStreetMap/CARTO. Angaben ohne Gewähr.
